# Firmware ESP32-P4 — caméra de nid

Projet ESP-IDF **v6.1**, cible **esp32p4** (ESP32-P4X-Function-EV-Board).

Dans VS Code (extension ESP-IDF), ce dossier `firmware/` est celui à ouvrir :

1. `ESP-IDF: Set Espressif Device Target` › `esp32p4`
2. `ESP-IDF: Build your Project`
3. `ESP-IDF: Select Port to Use` › port USB Serial/JTAG de la carte
4. `ESP-IDF: Flash your Project` (méthode `UART`)
5. `ESP-IDF: Monitor Device`

Procédure complète, câblage, mise en service et dépannage : voir le [README du dépôt](../README.md).
